All reproductions use the committed attempt-1 raw pages only (`attempt-1/raw/*.json.gz`, hashes in
`CAPTURE_MANIFEST.json`). The tested application commit is `78678d18` (the app code is identical to `c34eb2c`).
Run the replay harness: `python box_driver/ingest.py <repo> <fresh-data-dir>`. It writes each wallet's two pages into one
combined GTA body and calls `scanner.mass_search.workflow.replay_captured_wallet`.
The harness patches the catalog in-process (see D5). Recon: `box_driver/recon.py`. No Helius call is needed or allowed.

failure (`criteria_met = … and not unset`, asserted by `tests/test_mass_search_product_completion.py::test_unset_thresholds_do_not_pass`).

"qualifying". This needs a product decision. It is not silently changed here.
